Open workspace

Two modalities, two pipelines

X-ray

  1. Upload and validate the file
  2. Convert to grayscale
  3. Reduce noise
  4. Apply CLAHE or histogram equalization
  5. Detect edges if requested
  6. Run the classifier and Grad-CAM if requested

MRI

  1. Upload an image or DICOM slice
  2. Read dimensions and voxel spacing
  3. Normalize intensity
  4. Denoise and enhance contrast
  5. Select 2D slices
  6. Run U-Net, then view the mask and overlay

Built with

Image processing and AI inference live in separate modules, so models can be swapped later.
